# BeadsNakama

BeadsNakamaは、色付きのビーズを使ってピクセルアートデザインを作成するインタラクティブなウェブアプリケーションです。

## デモ
https://code4fukui.github.io/beads-nakama/

## 機能
- 四角形または六角形のピクセルアートデザインを作成
- デザインキャンバスのサイズを調整
- あらかじめ用意されたパレットから色を選択
- 方向ボタンをクリックしてデザインを移動
- 「全クリア」ボタンでデザイン全体をクリア

## 使い方
1. テキスト入力フィールドでデザインキャンバスのサイズを調整します。
2. ドロップダウンメニューからビーズの形状（四角形または六角形）を選択します。
3. カラーパレットをクリックして色を選択します。
4. デザインキャンバスをクリックして、選択した色のビーズを配置します。
5. 方向ボタンを使ってデザインを移動します。
6. 「全クリア」ボタンをクリックしてデザインをリセットします。
