# BeadsNakama

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

BeadsNakama is an interactive web application for creating pixel art designs using colored beads.

## Demo
https://code4fukui.github.io/beads-nakama/

## Features
- Create square or hexagonal pixel art designs
- Adjust the size of the design canvas
- Select colors from a predefined palette
- Move the design by clicking the direction buttons
- Clear the entire design with the "All Clear" button

## Usage
1. Adjust the size of the design canvas using the text input fields.
2. Select the shape of the beads (square or hexagonal) from the dropdown menu.
3. Click on the color palette to select a color.
4. Click on the design canvas to place beads of the selected color.
5. Use the direction buttons to move the design.
6. Click the "All Clear" button to reset the design.
